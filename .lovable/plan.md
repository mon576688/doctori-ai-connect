
# Progressive Web App (PWA) Support for Doctori AI

## What You Get

- Users can **install Doctori AI** directly from their phone's browser to their home screen
- The app opens **fullscreen** (no browser bar) and feels like a native app
- **Offline support** for basic features: previously visited pages, medicine cache, BMI calculator
- Fast loading with smart caching of assets
- Works on both **iPhone and Android**

**Important note**: This is NOT a downloadable `.apk` or `.ipa` file. Users install it directly from the browser (Share > Add to Home Screen on iPhone, or the install prompt on Android). No app store submission required.

If you later want a true app store listing, we can set up Capacitor as a separate step.

## Changes

### 1. Install and Configure `vite-plugin-pwa`

**File: `vite.config.ts`**

- Add `vite-plugin-pwa` plugin with:
  - App name: "Doctori AI"
  - Short name: "Doctori AI"
  - Theme color: teal/primary color from the app
  - Background color: white
  - Display: standalone (fullscreen, no browser bar)
  - Icons: 192x192 and 512x512 PWA icons
  - Service worker with runtime caching strategies
  - `navigateFallbackDenylist: [/^\/~oauth/]` to prevent caching OAuth redirects
- Workbox caching strategies:
  - **CacheFirst** for static assets (images, fonts, CSS, JS)
  - **NetworkFirst** for API calls (so data is fresh when online, cached when offline)
  - **StaleWhileRevalidate** for external resources

### 2. Add PWA Meta Tags to `index.html`

**File: `index.html`**

- Add `<meta name="theme-color">` for browser toolbar color
- Add Apple-specific meta tags for iOS support:
  - `apple-mobile-web-app-capable`
  - `apple-mobile-web-app-status-bar-style`
  - `apple-touch-icon`
- Add `<link rel="manifest">` (auto-generated by vite-plugin-pwa)

### 3. Create PWA Icons

**File: `public/pwa-192x192.png` and `public/pwa-512x512.png`**

- Generate properly sized icons from the existing favicon/logo
- These are required by the PWA manifest for the home screen icon

### 4. Create Install Page

**New file: `src/pages/Install.tsx`**

- A dedicated `/install` page that:
  - Detects if the app is already installed
  - Shows platform-specific install instructions (iOS vs Android)
  - Triggers the browser's native install prompt on supported browsers
  - Shows the benefits of installing (offline access, faster loading, home screen icon)

### 5. Register Install Route

**File: `src/App.tsx`**

- Add `/install` route inside the Layout

### 6. Add Install Prompt to UI

**File: `src/components/Navbar.tsx`** (or a new `InstallBanner.tsx`)

- Show a subtle "Install App" button/banner for mobile users who haven't installed yet
- Uses the `beforeinstallprompt` browser event
- Dismissible and remembers if user declined

## Technical Details

### Caching Strategy

| Resource Type | Strategy | Reason |
|--------------|----------|--------|
| App shell (HTML, JS, CSS) | CacheFirst | Fast loading, updates on next visit |
| Images and fonts | CacheFirst | Rarely change |
| Supabase API calls | NetworkFirst | Fresh data when online, cached fallback |
| Edge function calls | NetworkFirst | AI responses need to be live |
| External CDN resources | StaleWhileRevalidate | Balance freshness and speed |

### Offline-Available Features

These features will work without internet:
- Previously viewed pages (cached HTML/JS)
- BMI Calculator (pure client-side)
- Previously searched medicine results (cached API responses)
- Chat history (already in localStorage for guests)
- UI navigation and browsing cached content

Features that require internet:
- New AI chat conversations
- Live doctor search
- Booking appointments
- Drug interaction checker (needs API)

### PWA Manifest Configuration

```text
Name: Doctori AI - Your Virtual Health Assistant
Short Name: Doctori AI
Start URL: /
Display: standalone
Theme Color: #0d9488 (teal)
Background Color: #ffffff
Orientation: portrait
Categories: health, medical
```
